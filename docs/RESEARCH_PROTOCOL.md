# BBAG 阶段 0 研究协议

本协议固定系统研究接口和后续实施边界。当前样例使用合成数据、`ENGINEERING_TEST` 用途和 `DRAFT` 状态，演示值只用于 S0 配置与记录验证，不构成正式研究批准或经济结论。

## 当前授权范围

本阶段建设工程骨架、标准契约、配置校验、JSON Schema 导出、实验清单和审核交接。S1 的因子算子与公式执行、S2 的 QuantConnect 接入，以及后续模型调用、收益检验、优化和部署均不在本次范围。

研究初始方向为单一市场、单一频率和单一数据适配器的美股日频价量因子。具体参数由协议配置管理，未知值及其决策责任保留在待确定清单中，不从样例反推已获授权。

## 数据与时间关系

标准接口需要能够表达证券标识、数据来源、字段、频率、时区、复权口径和实际可用时间。历史股票池按当时状态构造；退市、更名、拆股和分红在后续数据实现中处理。

后续业务使用的数据必须满足以下时间顺序：

```text
字段实际可用 → 信号形成 → 下单 → 最早可成交 → 退出
```

未来收益只能用于标签，特征服务不得读取未来标签。标签必须与实际入场和退出规则匹配；训练时只使用已经成熟的标签。S0 校验配置所表达的规则和边界，真实数据上的时间因果审计由后续阶段落实。

## 数据分区与最终测试隔离

开发区用于候选生成、参数选择、模型比较和失败复盘。最终测试区在流程冻结后由受控执行者使用；冻结后新增数据用于前向观察。样例中的历史日期只用于非重叠和越界反例，不表示这些日期已经取得数据、封存或形成真实未见样本。

S0 的日期检查是协议一致性检查，不是已部署的数据访问控制。S2 必须在适配器或受控服务中执行实际权限限制，开发接口和生成代理不能借直接查询绕过封存边界。

最终测试的原始数据、指标、图表、排名、解释、评审意见、调参建议和派生摘要都属于独立审计内容。它们不得经开发记忆、生成提示、检索索引、自动摘要或常规导出回到研究循环。披露按协议留痕；一旦被用于改选方案，该区间即登记为已用于开发决策。

## 标签与交易假设

预测期与调仓期分别配置。日线收盘数据形成的信号只能在之后可执行的价格上入场；不能无条件按同日收盘成交。持有期限、退出时点、重叠持仓、资金占用和不可交易时的退出处理需要在正式研究前确定。

费用、点差、滑点、成交限制及适用的融资和借券成本均须显式配置。S0 的示例成本和风险数值仅检验类型和范围，不能当作已验证的市场实现假设。

## 预算与结果口径

S0 不发起外部模型或交易平台请求，相应调用预算为零。未来研究还需约束不同配置数、模型调用、回测任务、并发、运行时长和费用。重复结果不能重复记账，真实重试消耗须照实记录。

工程正确、平台集成和因子经济证据分别报告。适用评估的执行有效性为 VALID 时，才可产生 SUPPORT、REJECT 或统计 INCONCLUSIVE；技术错误、未完成任务和未知状态保持 NOT_EVALUATED。S0 没有因子经济评估，不能生成有效 alpha 或平台通过结论。

候选前向经济验证使用 ECONOMIC_VALIDATION；固定基准或夹具的工程演练使用独立 ENGINEERING_TEST 记录，后者不能改变被拒候选的经济状态。

## 冻结与模型更新规则

后续 S6.4 要求最终配置有版本匹配的审计、Research、含成本 LEAN 和必要对账证据；配置变化令受影响旧证据失效。最终测试不能代替开发复验，单因子回测不能代替最终组合自身的交易验证。

固定模型核对冻结工件和清洗器。滚动模型冻结初始工件、训练和更新准入规则，允许按规则合法生成且完成就绪校验的新工件，保存父版本、训练截止和启用时间。禁止把未来训练的权重或清洗器回灌历史；训练规则、参数选择或特征处理实质变化需要新版本和开发复验。

## 正式研究前的待确定事项

| 事项 | 需要固定的决定 |
|---|---|
| 股票池与数据 | 数据权限、历史覆盖、字段时点、流动性筛选及复权 |
| 标签与交易 | 预测期、形成和成交规则、退出及调仓周期 |
| 评价协议 | 基准、滚动窗口、跨界标签处理、不确定性和准入门槛 |
| 成本与风险 | 费用、滑点、成交和借券约束、仓位与回撤限制 |
| 资源与预算 | 候选、模型调用、平台任务、并发、时长和费用上限 |
| 最终审计 | 数据分区、访问主体、披露范围、晋升与归档条件 |

在这些事项被正式确定之前，样例协议维持 DRAFT。S0 成功表示接口和规则能够被校验，不代表上述待定事项已经解决。
