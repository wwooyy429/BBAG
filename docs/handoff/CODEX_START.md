# Codex 开发包使用说明

本包用于启动 BBAG 的分阶段开发。先阅读 [开发报告](CODEX_DEVELOPMENT_REPORT.md)，再查看 references 中的完整规范；templates 中提供阶段交付模板。

[用户提供的原始流程图](references/WORKFLOW_REFERENCE.png) 用于核对业务节点；S6.4 复验、技术异常分支和信息隔离以本批次完整规范为准。SOURCE_MANIFEST.json 记录来源与快照哈希，manifest.json 记录本包文件校验值。

当前项目处于规划阶段，首个开发任务为 S0。此包不包含已经实现的系统源码、真实 QuantConnect 运行证据或因子经济结论。首次执行时，以用户指定的 BBAG 项目目录作为工作根，核实实际文件和适用的 AGENTS.md；不要在本包的 references 快照中开发。

## 建议的首次任务

将下段作为启动开发时的任务指令使用：

> 请根据本包 CODEX_DEVELOPMENT_REPORT.md 和 references 中的规范，在我指定的 BBAG 项目目录执行 S0 研究协议与工程骨架。固定研究协议、阶段目标、数据和结果契约，建立最小可运行入口及配置校验，保存准确版本和原始自测证据。当前只交付 S0，不自动推进全部阶段。未确定的研究参数保留为显式配置并报告，不编造数据权限、平台结果或测试通过。提交开发结果时使用 templates/STAGE_HANDOFF_TEMPLATE.md，为独立审核准备源码、环境、复现步骤和证据；最终测试及派生内容保持隔离。

## 后续阶段

每次只指定一个阶段或明确的子里程碑。按前置能力和阶段验收结论推进，保留候选与配置变化记录。开发报告与完整规范出现冲突时，先依据 manifest.json 核对版本并报告差异，不静默混用不同版本。

文件校验清单用于确认交接包内容完整，不能作为系统测试通过的证据。
