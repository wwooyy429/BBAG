# Codex 阶段开发交付报告模板

本模板由开发者在实际完成对应工作后填写。未取得证据的项目保留未验证，不预填通过。

## 交付对象

| 字段 | 填写内容 |
|---|---|
| 阶段或子里程碑 | 待填写 |
| 实施范围和前置结论 | 待填写 |
| 源码提交或内容哈希 | 待填写 |
| 配置与数据版本 | 待填写 |
| 环境和依赖版本 | 待填写 |
| 运行用途与候选或基准编号 | 待填写 |

## 实现与需求对应

| 需求编号 | 实现文件或接口 | 自测方法 | 原始证据位置 | 完成状态 |
|---|---|---|---|---|
| 待填写 | 待填写 | 待填写 | 待填写 | 未验证 |

## 复现步骤

1. 说明环境准备与依赖。
2. 说明输入、配置、日期范围和所需权限。
3. 提供实际使用的运行及测试命令。
4. 指明原始输出、日志和平台结果的位置。

## 实际执行情况

| 检查或用例 | EXECUTED 或 STATIC_ONLY 或 NOT_RUN | 实际结果 | 证据 | 限制与补验条件 |
|---|---|---|---|---|
| 待填写 | NOT_RUN | 未验证 | 待填写 | 待填写 |

## 状态与后续动作

- 开发自评的工程状态：待填写，独立验收待进行。
- 平台集成状态：未运行或按实际证据填写。
- 经济证据状态：未评估；仅适用阶段按真实有效评估填写。
- 评估执行有效性：未运行，或按实际任务填写。
- 当前候选是否允许冻结或晋升及依据：待填写。
- 已知缺陷、未验证项和对应风险：待填写。
- 代码或配置改变导致哪些旧证据失效：待填写。
- 实验配置数、实际执行次数、模型调用和费用：待填写。
- 提交给审核者的固定源码、样本、环境、命令及证据清单：待填写。

最终测试及其派生内容不随开发包交付。涉及模型时，分别记录固定工件或滚动训练规则、逐次工件谱系、训练截止时间和就绪状态。
