## 本轮离线能力

| 能力 | 实现及限制 |
|---|---|
| 快照时钟 | 原 request.as_of 是该快照的冻结知识截止，retrieved_at 不早于它；身份、退市、更名起止、成员和公司行动知识时间不得越过它；后续选择 as_of 不得推进到快照之外。已公告但未来生效的事件保留，每个信号另按其实际知情/生效时间过滤。独立审核仅在 ecf 的声明契约范围关闭 S2-N01，供应商真值仍未验证。 |
| 分批读取 | 在首个读取前授权整个原请求及全部子请求；日期/资产分片保持字段、用途、分类、祖先与知识截止，不通过换批次放宽权限。结果保留每批原始来源，不伪造一个合并后的“原始字节”摘要。 |
| 合成快照缓存 | 仅 SYNTHETIC / LOCAL_DATA。精确请求、策略、代码、提供者和日历版本等绑定缓存身份；原始字节、规范 bundle 和存储校验互相复核；相同身份的不同内容拒绝覆盖。命中仍先门禁和来源复核，不自动重试，不增加任何真实平台尝试。 |
| 历史身份解释 | 按每个信号输出流动性筛选前的身份/上市/退市/成员/已知 ticker 纳入或排除原因。不给过去输出未来 ticker 或未来知识时刻，也不把末期名单当历史成员。 |
| 公司行动链 | 对一段静态持仓逐日记录拆股后的股数和分红现金；不计算复权价格、总收益、策略交易或经济结论。同一日混合拆股/分红缺先后顺序和现金基准时明确拒绝。 |
| 质量自一致 | 独立入口核行键/缺失字段唯一、可用与存在关系、观察标志以及汇总计数/覆盖率。它不替代原固定夹具独立答案，也不认证供应商真值。 |
| 累计预算只读计划 | 从明确固定的完整历史账本链及 metadata 读取实际尝试；已核摘要的 JSON payload 直接严格解析，已核数据库字节构成隔离内存查询快照，不按原路径二次解析／查询。保留来源/事件/完整性、缺链/重复及首尾稳定性检查，不创建新运行库恢复完整额度。输出始终为离线预览，不授予 dispatch、grant 或平台 PASS。 |

缓存数据面与控制通道保持分离。本地新存储拒绝 QUANTCONNECT_CLOUD，即使调用者声称在 Cloud 运行也不能借此落地。真实 SID、事件序列、行情及可重建派生值仍留在 Cloud。原 `MarketPanel.source=synthetic_fixture` 和 S1 数学模块不放宽，不用 ticker 假冒稳定 SID，不用 model_construct 绕过来源验证。

当前标准快照要求至少一个显式日历会话；有会话但 bars 为空可用于报告真实缺失。纯无会话日期段不会被补造日历或静默写成成功快照，调用方应结合明确日历选择分批窗口。真实提供者的空会话结果状态、历史日历完整性及后续云存储仍须在对应适配中实现和验证。

## 本地入口与证据

`s2-offline-check` 在提交后的源码上使用固定合成夹具，实际执行分批、快照写入/复用、历史身份解释、质量核对和静态持仓权益；不调用远程平台，不登记真实任务。缓存路径放 artifacts，数据源明确为 SYNTHETIC，重新调用必须保持相同代码/请求/版本身份方可命中。调用次数只标为合成 fetch，不能登记为 Research。

库级 code_commit 是显式调用者声明，不自行认证宿主；该 CLI 在缓存 I/O 前及结果返回前核真实 Git 根、干净起止 SHA，并把全部包源码、固定配置/原始夹具、依赖锁与项目元数据逐字节比对该提交的 Git blob。assume-unchanged/skip-worktree 不能用来掩盖这些输入的改变。演练还在缓存创建前重建整份 raw→标准 bundle，身份/成员/公司行动元数据与配置必须一致，不能仅凭行情字段相同返回成功。

`s2-campaign-plan` 读取 `configs/s2.offline-campaign.json` 声明的完整历史链；配置只有原文件位置、摘要和负责人边界，没有行情或凭据。缺少原文件、摘要不匹配、复制遗漏、UNKNOWN/活动未解决或不一致记录时拒绝，不能退化为从零开始。审阅副本可显式指定历史根目录；便携副本不是新运行台账。配置和计划都不认证负责人身份，不构成运行许可。

```powershell
python -m bbag s2-offline-check --config configs/s2.example.json --cache-dir artifacts/s2-offline-cache
python -m bbag s2-campaign-plan --config configs/s2.offline-campaign.json
python scripts/verify_stage2.py --output-dir artifacts/verification/S2/<new-sha>
```

源码包不附原始历史账本时，campaign-plan 应明确拒绝缺输入；CI 使用合成账本验证同样的读取/拒绝规则，不冒充读取过负责人原库。官方 S2 十项采集继续覆盖完整项目 pytest、三阶段 Schema、配置/固定合成参考及 PENDING 门禁；离线新增能力另保留实际命令和 stdout/stderr。交审报告只记真实运行结果，不预填通过。
