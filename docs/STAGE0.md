# BBAG 阶段 0 开发与验收

S0 将研究要求转为可读取和可校验的协议，建立可安装项目、标准接口、实验记录与版本审核流程。阶段边界见 [研究协议](RESEARCH_PROTOCOL.md) 和 [完整路线](ROADMAP.md)。

## 目标与交付

| 目标 | 交付物 | 验证方法 |
|---|---|---|
| 可重复启动 | Python 项目、依赖锁、模块与命令入口 | 新环境按锁定依赖安装并调用 CLI |
| 标准接口 | 类型化研究、数据、因子、标签、交易、评估、实验和发布契约 | 缺字段、未知字段、错误类型、非法范围被拒绝 |
| 时间与数据边界 | 开发区和最终区规则、标签与执行时间约定 | 重叠区间、非法时间和越界请求的配置反例 |
| 协议可重放 | JSON 样例、规范化配置和实验清单 | 相同配置哈希稳定，输出记录关联版本及用途 |
| 明确审计状态 | 审核回执接口和 SHA 一致性检查 | 缺失、待审核、错误版本不能被当作通过 |
| 固定版本交付 | 实现提交、开发报告、原始证据和审核包 | 包内源码与 commit、文件哈希一致 |

本阶段不实现因子算子、公式计算、IC、收益或回测；不调用 GPT API、QuantConnect 或真实交易账户。标准契约中的未来业务字段是接口，不是已完成的运行能力。

## 可运行入口

```text
python -m bbag validate --config configs/s0.example.json
python -m bbag init-experiment --config configs/s0.example.json --output-dir artifacts/experiments --run-id s0-demo
python -m bbag schemas --output-dir contracts
python -m bbag schemas --output-dir contracts --check
python -m bbag check-review --receipt <审核回执路径> --commit <待审完整SHA>
```

配置校验成功只表明结构和配置间约束有效，研究就绪仍为否。无效配置应有结构化错误和非零退出码；审核材料缺失、PENDING 或 SHA 不一致时，审核检查应返回阻断结果。

实验输出包含规范化协议及实验清单，保存协议哈希、代码版本、工作树状态、阶段、用途和未评估状态。实验编号和输出路径须检查，既有实验不得被静默覆盖。不能将有未提交修改的运行冒充准确提交上的验证。

Schema 从运行契约生成并纳入 Git。导出后应与已提交 Schema 一致；跨字段时间、状态等语义约束仍由运行契约校验，不能只凭通用 Schema 阅读认定语义完整。

审核回执检查器只检查结构、状态及提交 SHA 的一致性，不认证审核者身份，不授予合并权限，也不执行 Git 合并或阶段推进。

## 开发验证要求

- 有效样例可校验并生成实验清单，参数状态明确为 DRAFT，外部调用预算为零。
- 缺必填、未知字段、错误类型、布尔值冒充整数、负预算和非有限数值有明确拒绝行为。
- 非法日期、重叠分区、开发查询越界和时间规则冲突被发现。
- CLI 的正常、错误和审核待定路径有稳定退出码与可读结果。
- 输出防覆盖、路径边界、协议哈希与 Git 来源信息可检查。
- 缺失、PENDING 或过期审核回执不能构成有效独立审核；构造的测试批准只验证校验逻辑，不能作为真实批准。
- 实际测试运行保存原始输出和 JUnit 记录；源码、配置和依赖改变后重跑受影响检查。

S0 的局部验证不等于 F01—F08 全业务路径已经执行。后者需要后续真实能力和对应证据。

## 交给 GPT Work 的审核材料

先提交实现，再以该准确 SHA 生成阶段交付目录，至少包含固定源码、依赖锁、样例、运行说明、原始验证结果、开发报告、审核任务、文件哈希清单和未填写的独立审核模板。生成物放在 Git 忽略的 `deliverables/` 或 `artifacts/` 中。

报告在提交后生成，以避免报告试图包含自己的 commit SHA。审核者从准确提交或包内快照独立执行，核对开发日志，补充边界与数值反例。最终结果分别给工程、平台和经济证据结论，未运行的部分明确标记。

S0 交付后可以处于 READY_FOR_REVIEW，但独立审核仍为 PENDING。只有 GPT Work 对准确实现提交给出真实通过结论、阻断问题处理完毕并核实适用范围，才具备合并评估资格。当前任务仍停在 S0；进入 S1 需要用户授权。

## 已知能力边界

本地推送钩子、草稿 PR 和项目规则辅助防止未经审核的 main 更新，不是服务器端保护证明。回执文件可以检查一致性，不能凭一个自填 APPROVED 字段认定审核者身份或合并权限。外部审核与仓库服务器保护状态应在每次交付报告中如实列明。
